# รายงานตรวจสอบ Krob (ครบ) v0.9

## สรุปสถานะ
- แกนหลักแข็งแรง: โมเดลวันแบบ logical day (เริ่ม 08:00), `buildDay`, `dueReminders` และ UI สไตล์ iOS ทำงานถูกต้องในเส้นทางปกติ `tsc`/eslint สะอาด
- จุดอ่อนใหญ่สุดคือชั้นซิงค์ใน `src/lib/store.tsx`: ดึงข้อมูลครั้งเดียวต่อ session, ไม่ retry, เขียนทับทั้งก้อนแบบ last-writer-wins และมีเส้นทางที่ state ว่างทับข้อมูลบน server ได้
- ระบบแจ้งเตือน: ถ้าตั้ง `CRON_SECRET` ใน Vercel ขณะใช้ v0.7 cron จะโดน 401 ทุกนาทีแบบเงียบ และ error ตอนส่ง push ถูกกลืนหมด
- บั๊กตรรกะที่กระทบทุกวัน: รอบยิมรีเซ็ตเป็น D1 หลังวันพัก, เช็กอินจากแท็บยิมไม่ติ๊กรายการใน Today, เทรนด์น้ำหนักคำนวณผิดเมื่อชั่งไม่ทุกวัน
- UI สวยและสม่ำเสมออยู่แล้ว งานที่เหลือเป็นการขัดเกลา: ล็อกหน้าจอโดยไม่ทำให้ร่าง journal หาย, splash แทนจอขาว, จุดสัมผัส 44pt, กราฟน้ำหนักมีแกน/เส้นเป้า

## ตัดออก
- NaN% สรุปกลางคืน: หารด้วย 0 ไม่ถึง (sleep อยู่ใน items)
- คีย์บอร์ด iOS ทับ sheet / sheet ไม่มี max-height: จำลองแล้วไม่เกิด ความสูงรวมพอดีจอ
- `/api/push/vapid` เขียน `app_url` จาก Host: subscribe ที่ต้อง token เขียนทับทันทีอยู่แล้ว, ผู้ใช้คนเดียวไม่เปิด preview
- เทียบ cron secret แบบ constant-time, security headers/CSP, PBKDF2 สำหรับ verifier ท้องถิ่น: ภัยไม่จริงสำหรับแอปคนเดียว, CSP เสี่ยงจอขาวบน iPhone
